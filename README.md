# Game Collection 

---

## Overview

Game Collection is a desktop application developed in Python using CustomTkinter for the graphical interface. It integrates with the IGDB API to fetch game data and uses SQLite as a local database to persist user collections. The app allows users to search for games,and organize them into custom lists.

---

## Setup

````
git clone https://github.com/CarlosArthurM/Game-Collection.git
cd Game-Collection
python -m venv venv
pip install -r requirements.txt
````
